# Chaand Mart mock API, version 2

All data is synthetic. Used in Week 2 (S04 late-parcel alert, S06 cost check) and the readiness exercise.

- orders.json: 300 orders
- shipments/<tracking_no>.json: the courier's answer for one parcel (268 files)
- messages.json: 10 customer messages (the Session 1 set)

Live at https://mehakrafiq.github.io/chaand-mart-api/ (for example /orders.json or /shipments/TP-701293.json).
